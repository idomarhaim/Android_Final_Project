## Necessity (`/adversarial-review` §1) — and the argument had to be rebuilt

**The obvious case for the amendment fails.** One supporting instance, self-generated, arising from an
unusual manoeuvre the rule already implicitly discourages, is not grounds to grow a rule. On the
missed-instance argument alone this should be **dropped**.

**What survives is a different and stronger argument: the rule currently lists a remedy that does not
work.** *"Stage as late as possible (shrinks the window, never closes it)"* is only a mitigation if the
window opens at `git add`. Under the corrected model the window opened when the **file was written**,
so lateness shrinks almost nothing. **A remedy named in a rule that does not do what it says is worse
than no remedy**, because it is *load-bearing on the days it matters* — a session that has staged
late believes it has bought something.

**So the amendment is necessary, and the necessity is about the remedy, not the instance** — which
also changes its shape. It is **not a new clause.** It is a correction to one sentence and a downgrade
of one listed remedy, in two files. Scoping it that way is the fallback's own output: had this shipped
as the candidate proposed — a finding worth its own clause — it would have added weight for a case
that supports it once.
