## 🏗️ Added
- **Toolchain:** Gradle 8.10.2 wrapper, SDK platform 35 install, JDK-21 pin, debug keystore SHA-1.
- **Build:** version catalog, AGP 8.7.3 / Kotlin 2.0.21 / Compose BOM 2024.12.01, Hilt via KSP, google-services (placeholder json), `local.properties`-driven web client id.
- **Domain:** `Goal`, `Task`, `ProgressEntry`, `User`+`Leveling`, `Social`, `ProgressSummary`, `Recommendation`, `Challenge`; repository interfaces; `BuildSummaryUseCase`.
- **Data:** Firebase Auth (Google Sign-In) with profile bootstrap; Firestore repos for goals/tasks/progress/social (task completion is a points+progress transaction); Storage image upload; GROQ recommendations via Cloud Functions with local fallback; Health Connect / Google Tasks stubs.
- **UI:** Material 3 theme (dynamic color), reusable `ProgressRing`/`GoalCard`/`HorizontalBarChart`/`Avatar`, navigation + auth gate.
- **Features:** Sign-in, Goals (list/detail/add-edit), Tasks with points, Dashboard (rings, AI coach, weekly share), Social (leaderboard + friends + feed + add-by-code), Profile (points/level, friend code, sign out), Analytics (charts), Challenges (preview).
- **Backend:** `functions/` GROQ proxy (getRecommendations, classifyTask, scoreTask); `firestore.rules`, `storage.rules`, `firebase.json`, `.firebaserc`, indexes.
- **Docs:** README, `docs/SETUP.md` (credentials + SHA-1), `docs/ARCHITECTURE.md`, AGENTS.md, TODO backlog, `.github` instruction scaffold.
