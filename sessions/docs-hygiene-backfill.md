## Task

### 1 · Correct the false JDK claim (one line, do this first)

`scripts/README.md:48-49` says *"the machine default is JDK 25, which AGP rejects"*.
[AGENTS.md:80](../AGENTS.md#L80) corrected that on 2026-08-15 — it was a **broken JDK 21
install**, not JDK 25. Left open by `changelog-index-backfill` as out of its scope.
Fix the sentence to match AGENTS.md, and check the same claim has not been copied
anywhere else (`grep -rn "JDK 25" .`) — an unhedged wrong claim propagates by copying,
and this one already has one known copy.

### 2 · Backfill `> **Summary:**` where it can be done mechanically — and only there

**7 of 84** changelog session files carry the mandatory `> **Summary:**` line. It has
been required since template v16 (2026-08-05); the handful that have it are exactly that
week's sessions, and every session since has skipped it. The index generated by
`scripts/New-ChangelogIndex.ps1` renders the rest as bare links.

**The constraint that shapes this task:** these are *other sessions'* accounts of *their
own* work. Authoring a summary for a session you did not run is inventing provenance, and
it is the same hazard `read-before-write.md` names for changelog files.

So:

- **Extract, never compose.** Where the file's own opening paragraph or an existing
  `## What shipped` heading already states the summary, lift it **verbatim** (trimmed to
  one line) into the `> **Summary:**` position.
- **Where nothing in the file supplies one, leave it bare.** Do not write a sentence
  about work you did not do.
- **Report both counts** — how many were backfilled by extraction, how many were left
  bare and why. A silent partial backfill reads as a completed one.
- **Regenerate the index** afterwards (`scripts/New-ChangelogIndex.ps1`) and confirm the
  new summaries appear between the markers.
- **Add the requirement to the pre-commit hook only if it is cheap** — a session whose
  own file lacks the line is the one case worth catching, and the hook already refuses a
  commit whose changelog is unindexed. If it is not a small change, say so and stop;
  do not grow this task.
